# CIS Benchmark Violation Dashboard

This project is a professional, interactive Streamlit dashboard to visualize and analyze CIS Benchmark compliance violations across different operating systems and control categories.

## 🌐 Live Dashboard
Deployable to [Streamlit Cloud](https://share.streamlit.io/)

## 📦 Features

- OS & control-based filters
- Grouped control categories with Select All/Clear All
- Time-based filtering
- Heatmaps, bar charts, line trends
- Downloadable filtered dataset

## 🚀 How to Run Locally

```bash
pip install -r requirements.txt
streamlit run final_streamlit_dashboard.py
```

## 📁 Files

- `final_streamlit_dashboard.py`: Main dashboard app
- `simulated_cis_control_violations.csv`: Sample dataset
- `requirements.txt`: Required packages for deployment
